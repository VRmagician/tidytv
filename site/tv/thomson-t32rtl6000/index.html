Debloat the Thomson T32RTL6000

Android TV 9 · 34 apps on the list · tested on a real set

This Thomson set ships with telemetry, analytics and recommendation rows, a data consent agent, and content and promo rows that install partner apps. It also carries preinstalled stores, factory and demo utilities, and a Google Assistant that takes memory. Each app has its own switch in the app, so you decide which ones to turn off.

The list is cross-checked against a sister set on the same Realtek platform. TidyTV turns these apps off from your phone over Wi-Fi, saves a backup first and never deletes anything, so the tuner and remote stay as they were. What always stays on

  • The Realtek live TV tuner, or channels disappear
  • The remote and Bluetooth pairing apps
  • The FastCast Miracast receiver
  • Google Play, Play Services, the web view and keyboard

Good to know on this model

  • The system channel database stays empty on this firmware, so launcher channel rows do nothing until a firmware update fills it.
  • Google Assistant is on the list. Turning it off kills the remote's mic button.

How to do it

  1. Turn on developer options On the TV, open Settings › System › About and select the build number 7 times. Then turn on USB debugging, and Network debugging if you see it.
  2. Tap your TV in TidyTV Your phone finds the TV on the Wi-Fi. Tick "Always allow" and press Allow when the TV asks.
  3. Review, then tidy TidyTV saves a backup, shows these apps with switches, and turns off the ones you pick, checking each one.

Questions

Can I get the old home screen back on my Thomson T32RTL6000?

Yes. Restore everything in the app turns every app back on and puts the old home screen back in one tap. TidyTV only switches apps off, so nothing is ever deleted.

Will the voice button still work on my Thomson?

Not with the default list. It turns off Google Assistant, which the mic button uses. Switch it back on in the app if you use voice.

Does TidyTV delete anything on my Thomson T32RTL6000?

No. It turns apps off with Android's own setting, saves a backup first and checks each one. You can turn any app back on with its switch.
