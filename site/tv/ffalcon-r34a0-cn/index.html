Debloat the FFALCON r34a0

Android 5.1 · 22 apps on the list · tested on a real set

This FFALCON r34a0 is a China-market TV on old Android 5.1 with only 1 GB of memory and 8 GB of storage. It has preloaded apps that can be hidden, and a boot ad. The list is short, at 22 apps, and applies only to this firmware.

Here is what is known about testing it. The firmware refuses the usual way of turning apps off, so apps are hidden instead, and a new home screen app will not install. TidyTV can only debloat this set, over Wi-Fi, with a backup first and nothing deleted.

Good to know on this model

  • This firmware denies the usual way of turning apps off, so the list hides them instead and undoing it uses a different command.
  • New home screens are refused, so only the stock CyberUI home screen can be used.
  • Installing apps from a computer is blocked until two settings are switched on.

How to do it

  1. Turn on developer options On the TV, open Settings › System › About and select the build number 7 times. Then turn on USB debugging, and Network debugging if you see it.
  2. Tap your TV in TidyTV Your phone finds the TV on the Wi-Fi. Tick "Always allow" and press Allow when the TV asks.
  3. Review, then tidy TidyTV saves a backup, shows these apps with switches, and turns off the ones you pick, checking each one.

Questions

Can I put a new home screen on my FFALCON r34a0?

No. This firmware refuses any home screen app, so the stock CyberUI home screen stays.

Is this model handled the same way as others?

No. This old Android 5.1 firmware refuses the normal setting, so apps are hidden instead. It was tested on one unit on 21 October 2026.

Can I undo it?

Yes. Hidden apps can be unhidden, and Restore everything in the app turns every app TidyTV changed back on.
